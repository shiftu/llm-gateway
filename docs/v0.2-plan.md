## §1. Confirmed Premises

P1. **v0.2 is a Launchability Sprint, not a feature flood.** Every task answers "does this make it easier for someone who isn't me to deploy and use the gateway?"

P2. **AI-native MCP-only control plane is non-negotiable.** No web UI for writes. Read-only dashboard remains out of scope per v0.1 user decision (UC-3 declined). `tools/list` filtering at handshake is the delivery mechanism.

P3. **Dual-protocol inbound** (OpenAI + Anthropic) — confirmed in v0.1 R1, unchanged.

P4. **Multi-tenant as default.** No "legacy single-user mode." The `LLM_GATEWAY_TOKEN` env remains as bootstrap + lost-key recovery (per UC-R3-5).

P5. **Single static Go binary + SQLite.** No Python runtime, no Postgres, no Redis.

P6. **AI-native thesis stands.** The operator IS a coding agent, and the gateway's control plane IS the agent's tool call interface.

### Competitive positioning (recap from v0.1 R3 FINAL)

Three axes where llm-gateway is intentionally NOT LiteLLM:
1. **AI-native MCP-only control plane** — LiteLLM operates via REST admin API + UI; llm-gateway operates via MCP exclusively.
2. **Chinese-provider-first** — DeepSeek/GLM dual-protocol native support, reasoning-content field semantics.
3. **Single static Go binary, no Python runtime, no external state** — LiteLLM needs Python + Postgres/Redis.

v0.2 investments must deepen at least one of these three moats. LiteLLM-parity additions get scrutinized harder.

### Storage schema additions (v0.1 → v0.2 migration)

```sql
-- v0.1 → v0.2 migration (idempotent via user_version PRAGMA)

-- 1) Routing rules — condition-based dispatch
CREATE TABLE routing_rules (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  team_id     TEXT REFERENCES teams(id) ON DELETE CASCADE,  -- NULL = global rule
  priority    INTEGER NOT NULL DEFAULT 0,
  match_field TEXT NOT NULL DEFAULT 'model',                -- "model" | "kind"
  match_op    TEXT NOT NULL DEFAULT 'prefix',                -- "prefix" | "equals" | "regex"
  match_value TEXT NOT NULL,                                -- e.g. "deepseek-*", "glm-4-flash"
  provider_name TEXT NOT NULL REFERENCES providers(name) ON DELETE CASCADE,
  upstream_model TEXT,                                      -- NULL = use client's model name verbatim
  is_active   INTEGER NOT NULL DEFAULT 1,
  created_at  INTEGER NOT NULL,
  CHECK (match_op IN ('prefix', 'equals', 'regex'))
);
CREATE INDEX idx_routing_rules_team ON routing_rules(team_id);

-- 2) Admin audit log (immutable append-only)
CREATE TABLE admin_audit (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  ts          INTEGER NOT NULL,
  api_key_id  TEXT REFERENCES api_keys(id) ON DELETE SET NULL,
  team_id     TEXT,                                         -- denormalized
  action      TEXT NOT NULL,                                -- e.g. "issue_api_key", "revoke_api_key", "add_team"
  target_type TEXT,                                         -- "team", "api_key", "quota", "provider", "alias"
  target_id   TEXT,                                         -- the affected resource ID
  detail      TEXT,                                         -- JSON blob with request params
  ip_address  TEXT
);
CREATE INDEX idx_admin_audit_ts ON admin_audit(ts DESC);
CREATE INDEX idx_admin_audit_action ON admin_audit(action);

-- 3) RPM bucket now SQLite-backed (v0.2, opt-in via env LLM_GATEWAY_PERSIST_RPM=1)
-- (reuses usage_counters table with minute-based day_utc key; no new table needed)

-- 4) providers.api_key encryption
-- No schema change — encrypt/decrypt happens in Go layer transparently.
-- The column stays TEXT; encrypted payload is base64-encoded.
```

### Encryption-at-rest design

```go
package encrypt

// MasterKey wraps a 32-byte XChaCha20-Poly1305 key from LLM_GATEWAY_MASTER_KEY env.
// Derivation: SHA-256(env_value) → 32 bytes.
type MasterKey struct { /* ... */ }

func NewFromEnv() (*MasterKey, error)
func (mk *MasterKey) Encrypt(plaintext []byte) (ciphertext []byte, err error)
func (mk *MasterKey) Decrypt(ciphertext []byte) (plaintext []byte, err error)

// EncryptedProviderKey wraps the encrypted value + nonce into one base64 string:
//   base64(nonce(24) || ciphertext)
// Format prefix: "lgw_enc:v1:" for easy identification.
```

**Key rotation:** Not in v0.2 scope. Document that changing `LLM_GATEWAY_MASTER_KEY` after data is written renders provider keys unrecoverable. v0.3 will add re-key tool.

### Routing rules design

```go
type RoutingRule struct {
    ID             int
    TeamID         string
    Priority       int
    MatchField     string   // "model" | "kind"
    MatchOp        string   // "prefix" | "equals" | "regex"
    MatchValue     string
    ProviderName   string
    UpstreamModel  *string  // nil = pass through client model name
    IsActive       bool
}

// Resolver priority:
// 1. Team-scoped alias hit
// 2. Routing rules (sorted by priority ASC), first match wins
// 3. Team-specific default provider
// 4. Global default provider (fallback_eligible=1)
// 5. ErrNoRoute
```

### Dockerfile design

```dockerfile
# Multi-stage: goreleaser-built binary or go build
FROM golang:1.26-alpine AS builder
WORKDIR /src
COPY . .
RUN CGO_ENABLED=0 go build -o /bin/llm-gateway ./cmd/llm-gateway

FROM scratch
COPY --from=builder /bin/llm-gateway /llm-gateway
EXPOSE 7421
ENTRYPOINT ["/llm-gateway"]
VOLUME ["/data"]
ENV LLM_GATEWAY_DB_PATH=/data/state.db
```

Expected image size: ~10MB (scratch base).
